## Controls:
* `UP Arrow`: Accelerate (Manual Mode)
* `DOWN Arrow`: Brake / Reverse (Manual Mode)
* `LEFT Arrow`: Steer Left (Manual Mode)
* `RIGHT Arrow`: Steer Right (Manual Mode)
* `A`: Toggle Autopilot (ON/OFF)
